## Remote Server Cleanup v1.0.0

Initial controlled baseline of the Remote Server Cleanup administrative tool.

### Platform

- Windows PowerShell 5.1
- Windows Server 2016+

### Capabilities

- Multi-server cleanup
- PowerShell remoting
- WinRM validation
- WhatIf mode
- Temporary-file cleanup
- Recycle Bin cleanup
- SCCM cache cleanup
- Windows Update cache cleanup
- DISM cleanup
- IIS log cleanup
- Custom paths
- Process Viewer
- CSV and text logging
- Integrated Help

### Operational Classification

Administrative utility.

### Important

Production execution should follow normal change-management,
authorization, testing, and maintenance-window requirements.

This release represents the original v1.0.0 baseline and should not
be modified after publication.
